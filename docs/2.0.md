# Aroli Desktop 2.0 upgrade guide

2.0 turns the rice from a collection of independent controls into an adaptive
workspace. Existing installations keep their appearance and all previous
commands continue to work.

## Before updating

```sh
rice snapshot create pre-2.0
rice update --dry-run
```

No optional package is installed by an update. To use power profiles or
per-process GameMode after updating, opt in explicitly:

```sh
rice plugins install power-profiles-daemon gamemode
```

## New daily workflows

```sh
rice session apply laptop
rice session apply gaming
rice recover --dry-run
rice recover --snapshot latest
rice export ~/aroli-preferences
```

`rice import` restores visual preferences and reports selected optional
packages, but never installs them automatically. Game Mode temporarily takes
precedence over Power Saver and restores the original profile when it ends.

## Compatibility

| Component | Required behavior |
| --- | --- |
| Hyprland 0.56+ | Runtime `hyprctl eval` applies and restores Game/Reading mode effects. |
| Quickshell | Control Panel and Settings read CLI state; no persistent shell process is added. |
| Power Profiles Daemon | Optional; exposes power-saver and balanced, plus performance when hardware supports it. |
| Feral GameMode | Optional; wraps only commands launched with `rice gaming launch`. |
| Omarchy | Package installation remains through `omarchy-pkg-add`; no file below `/usr/share/omarchy` is changed. |
