# Identidade Umbra Liminal

## Conceito

**Limiar** é a passagem entre a base estável do Omarchy e a superfície pessoal
do Umbra. Por isso o Liminal não usa uma paleta fixa como assinatura: o
wallpaper fornece a cor, enquanto o sistema fornece a forma.

## Ativos visuais

1. Superfícies escuras e espaço negativo para conter o conteúdo.
2. Bandas de luminância e recortes de notch como estrutura recorrente.
3. Paleta derivada do wallpaper, não de um hexadecimal proprietário.
4. Marca correta para a plataforma atual: Omarchy no Omarchy, Arch no Arch e
   símbolo neutro em outras distribuições.

## Nome e atribuição

- Nome completo: **Umbra Liminal**.
- Forma curta: **Liminal**, quando o contexto Umbra estiver claro.
- Omarchy e Arch são marcas de suas respectivas comunidades; são exibidas
  apenas para identificar a plataforma ativa.
- O código continua sob [GPL-3.0-only](../LICENSE), com atribuição ao upstream.
