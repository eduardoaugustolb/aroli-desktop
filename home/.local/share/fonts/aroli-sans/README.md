## Aroli Sans

Original proportional family for Aroli communication (Regular, Medium,
SemiBold, Bold), built from its own drawings — companion to Aroli Mono.
Versioned binaries from `github.com/eduardoaugustolb/aroli/fonts/aroli-sans`
(`dist/*.otf`); desktop installs use OTF, web uses WOFF2.

The drawings are original and governed by that repo's root license; they
contain no third-party outlines. 167 glyphs: ASCII, precomposed Portuguese
accents, editorial punctuation, arrows and ©.
