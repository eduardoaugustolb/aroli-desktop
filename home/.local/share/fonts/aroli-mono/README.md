## Aroli Mono NF

Original monospace prototype for code, with Nerd Font symbols merged in
(the icon codepoints come from Symbols Nerd Font, see NERD-FONTS-LICENSE.txt;
the text drawings are Aroli's own, not derived from JetBrains Mono, Fira
Code or any other text font).

Versioned binaries from `github.com/eduardoaugustolb/aroli/fonts/aroli`
(`dist/AroliMonoNF-*.otf`: Regular, Medium, SemiBold). Ligatures
(`->`, `=>`, `!=`, `<=`, `>=`, `==`) need contextual alternates (`calt`);
the Aroli mark lives at U+100000.
